# Barbershop Appointment Management System

This project was prepared as a database project for a barbershop appointment management system.

The main purpose of the system is to manage appointments, customers, barbers, services, payments, and product usage in different branches of a barbershop.

## Project Content

The project includes:

- MSSQL scripts
- Oracle scripts
- stored procedures
- triggers
- test scripts
- requirement document
- ER diagram

## System Features

Some features implemented in this project:

- customer registration
- barber and branch management
- appointment creation
- appointment-service relation
- product usage tracking
- payment management
- stored procedures for business rules
- triggers for validation and control
- test scripts for checking the system
